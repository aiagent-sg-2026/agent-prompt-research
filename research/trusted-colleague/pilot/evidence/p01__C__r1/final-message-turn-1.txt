The likely cause is a many-to-many row multiplication: each invoice line is combined with each matching customer tag, producing multiple rows for the same invoice.

- Aggregate customer tags by customer or invoice into a single value, or use `EXISTS` if tags are only a filter.
- Join those already one-row-per-invoice results to `invoices`.
